# 경쟁 제품 비교

목표 기업의 메인 아이템과 기술·시장 분석을 바탕으로 경쟁 제품을 찾고, 입력된 웹 검색 결과와 RAG 근거만 사용해 비교한다.

## 규칙

- 웹 검색 결과에 실제로 들어 있는 회사·제품·사양만 경쟁제품으로 출력한다. 목표 기업 자신은 제외한다.
- 각 경쟁제품의 `source_url`은 입력된 웹 검색 결과의 URL 중 하나와 정확히 일치해야 한다.
- 성능 수치와 제품 사양을 추측하거나 서로 다른 측정 조건을 같은 기준처럼 비교하지 않는다. 출처에 수치가 없으면 `핵심지표값`을 빈 배열로 둔다.
- RAG 근거는 업계 기준과 비교 조건을 설명할 때만 사용한다. 웹에서 확인한 경쟁제품 사양의 출처로 바꿔 쓰지 않는다.
- 확인 가능한 경쟁사가 2곳보다 적으면 있는 만큼만 반환하고, 부족한 이유를 `비교한계`에 적는다.
- 목표 기업의 수치도 `technology_analysis`에 있는 값만 사용한다. 우위·열위는 같은 지표와 충분히 비슷한 측정 조건이 확인될 때만 적는다.
- 출력 `source_excerpt`는 해당 URL 검색 결과 내용에서 근거가 되는 짧은 문구를 그대로 골라 쓴다.

## 출력

`경쟁제품`(기업명, 제품, 핵심지표값: [{이름, 값}], source_url, source_excerpt), `비교표`: [{지표, 대상기업, 경쟁사: [{이름, 값}]}], `우위`, `열위`, `비교조건`, `비교한계`를 구조화해 반환한다.
